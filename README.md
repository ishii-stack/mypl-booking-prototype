# まいぷれ予約（mypl Booking）

## プロジェクト概要

本リポジトリは、「まいぷれ予約」の企画・設計・プロトタイプ・開発を管理するためのプロジェクトです。

私たちが目指すのは予約システムではなく、

**集客 → 予約 → 来店 → 口コミ → 再来店**

までを一つの体験として提供するAIマーケティングプラットフォームです。

------------------------------------------------------------------------

## プロジェクトの目的

-   地域店舗の売上向上
-   AIによる業務効率化
-   OEM展開可能な予約基盤の構築

------------------------------------------------------------------------

## 開発方針

「何を作るか」よりも「何を作らないか」を重視します。

新機能は **Feature Decision Matrix** に基づいて評価・判断します。
