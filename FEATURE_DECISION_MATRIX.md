# FEATURE DECISION MATRIX

Version 1.0

## 目的

予約機能に関する全ての機能を一覧化し、価値・工数・優先順位を共通基準で判断する。

## 評価基準

-   顧客価値
-   MRRへの貢献
-   OEM価値
-   AIとの親和性
-   開発工数（開発担当）
-   保守負荷（開発担当）
-   優先順位
-   採用判断
